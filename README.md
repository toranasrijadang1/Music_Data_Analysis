# Music_Data_Analysis
The system demonstrates a complete music streaming data analysis pipeline using Python.
Data cleaning and preprocessing improve the quality of analysis.
Artist and genre analysis helps understand listener preferences.
Listening-time and songs-per-day analysis helps identify listening behaviour.
Bar charts, pie charts, and line charts make the results easier to understand.
The project provides practical experience in data analysis and visualization.
